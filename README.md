# minhapoesia

Site público: leitura dos poemas a partir do JSON do repo de revisão.

- Não copia o acervo. Busca: `https://icmrocha.github.io/poesia/poesias.json`
- Mostra título, texto, tags e compilação
- Não mostra comentário, Checado nem Favorito
- Sem botão de salvar

Ligue o GitHub Pages deste repo na raiz (`index.html`).
